# Campaign and map payloads v1
Source layouts: Spellcross Reloaded level.cpp, SpellDEF and SpellMap::Load (original MIT restoration tools).
Script JSON is an ordered syntax tree represented as records: block / call / end / unknown, depth and original source line. ASCII keyword is normalized; original name and argument strings are preserved. Repeated commands are not merged and leading zeroes, percentages, placeholders and resource names remain unchanged. Source strings use byte-preserving U+00xx escapes; the original container also retains all whitespace/comments. UTF-8 companion text is provided where the selected text encoding succeeds. This is a data representation, not a new game-script interpreter. Unrecognized syntax is counted, not executed or discarded.
Tactical map metadata describes all eight layers: L1 sprite table and two-byte little-endian tile words (low 12 bits index, high nibble elevation), L2 sprite table with byte index (0 empty, 1-based otherwise) and byte flags, L3 ANM and L4 PNM resource lists and placements (frame offset/limit, coordinates and PNM origin), L5/L6 linear counterattack posts, L7/L8 loop/random sound lists and placements. Ground and objects are stored as independent raw binary arrays, row-major in original order. Trailing bytes are kept in hex; exact original source remains accessible. The new reader does not resolve references against the engine, infer nav padding or alter event behavior. Supported terrain names T11/PUST/DEVAST. No runtime loader yet.
